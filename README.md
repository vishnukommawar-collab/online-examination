# 🎓 ExamSphere — Enterprise Online Examination System

A modern, full-stack **MERN (MongoDB, Express.js, React, Node.js)** Online Examination Platform engineered with anti-cheating focus tracking, real-time proctored timers, automated grading, in-depth question explanations, and **100% turnkey readiness for Vercel deployment**.

---

## 🌟 Key Features

### 👨‍🎓 For Students / Candidates
- **Live Proctored Test Taking**: Real-time visual countdown timer with color-coded urgency alerts and auto-submission.
- **Anti-Cheat Monitoring**: Tab switch and window focus detection with strike counter and proctor logging.
- **Interactive Question Palette**: Fast jump navigation matrix showing Answered, Marked for Review, and Unanswered questions.
- **Instant Result & Explanations**: Immediate score calculation, Pass/Fail status, accuracy percentage, time taken breakdown, and detailed explanations for every question.
- **Past Examination History**: Review previous test attempts and print or save PDF score reports.

### 👑 For Examiners / Administrators
- **Executive KPI Dashboard**: Overview of total exams, registered students, total submissions, overall pass rate, and average score.
- **Exam Builder**: Create exams with custom titles, categories, durations, pass thresholds, and shuffle toggles.
- **Dynamic Question Builder**: Add questions with options, select correct answers, allocate marks, and author explanations.
- **Candidate Gradebook**: Real-time feed of candidate submissions, scores, and proctoring integrity flags.

### 🚀 Production & Cloud Ready
- **Vercel Serverless Ready**: Express backend configured to deploy seamlessly as Vercel serverless functions (`api/index.js`).
- **MongoDB Atlas + Turnkey Mode**: Seamlessly connects to MongoDB Atlas via Mongoose; includes an automatic high-fidelity in-memory fallback store if `MONGODB_URI` is not yet configured, allowing instant zero-config testing.
- **1-Click Demo Logins**: Pre-seeded demo credentials for instant testing without manual registration.

## 💻 Local Development Setup

### Prerequisites
- Node.js (v18 or higher)
- npm

### 1. Clone & Install Dependencies
```bash
# In the project root:
npm install

# In the client directory:
cd client
npm install
cd ..
```

### 2. Environment Variables (Optional)
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
*(If left empty, the system automatically runs in turnkey in-memory mode pre-seeded with sample exams!)*

### 3. Run Locally
```bash
npm run dev
```
- Frontend runs at: `http://localhost:5173`
- Backend API runs at: `http://localhost:5000`

## ☁️ Deploying to Vercel (Step-by-Step)

The project is pre-configured with `vercel.json` and a root build script ready for Vercel.

### Method 1: Deploy via Vercel Web Dashboard (Recommended)

1. **Push your code to GitHub / GitLab / Bitbucket**:
   ```bash
   git remote add origin https://github.com/<your-username>/online-exam-system.git
   git branch -M main
   git push -u origin main
   ```

2. **Import into Vercel**:
   - Go to [vercel.com](https://vercel.com) and log in.
   - Click **Add New...** → **Project**.
   - Select your `online-exam-system` repository.

3. **Configure Project Settings**:
   - **Framework Preset**: Other (or Vite)
   - **Root Directory**: `./` (leave as root)
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install && cd client && npm install`

4. **Environment Variables (Optional)**:
   Under **Environment Variables**, add:
   - `MONGODB_URI`: Your MongoDB Atlas connection URI (e.g., `mongodb+srv://user:pass@cluster0.mongodb.net/examsphere?retryWrites=true&w=majority`)
   - `JWT_SECRET`: A secure random secret string (e.g., `examsphere_prod_secret_2025`)
   - `NODE_ENV`: `production`

   *(Note: If you don't add `MONGODB_URI` initially, the application will still launch and run cleanly using the turnkey in-memory store!)*

5. Click **Deploy**! 🚀

---

### Method 2: Deploy using Vercel CLI

```bash
# Install Vercel CLI globally if you haven't:
npm install -g vercel

# From the online-exam-system root directory:
vercel

# For production deployment:
vercel --prod
```

## 🛡️ Anti-Cheating & Integrity Features

- **Window Blur & Tab Switch Detection**: Automatically increments an audit strike counter when a candidate navigates away from the exam tab.
- **Proctor Warning Modal**: Informs the candidate immediately upon returning to the window that their lost focus event was recorded.
- **Copy & Context Menu Protection**: Prevents easy copying of question prompts during examination.
- **Synchronized Countdown**: Automatically submits answers the moment time reaches zero.
